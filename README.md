# Embedded Systems Laboratory

NTU embedded systems coursework and **EchoPlay**, a voice-controlled music player integrating an STM32 microphone/Wi-Fi board, Raspberry Pi inference, and Bluetooth audio playback.

- [EchoPlay setup, source, models and validation](Final_Project/README.md)
- [Hardware demonstration](https://youtu.be/iaQB33fttS0)
- [Interactive system architecture](https://ilochen.github.io/projects/echoplay/)
- [Technical report](Final_Project/Report/Technical_Report.pdf)

`Lab1` through `Lab6` preserve the earlier lab application sources. `Final_Project` contains the integrated application, saved classifiers, training notebooks, example recordings, and reports. Board SDK and IDE support are external dependencies documented in the final-project setup guide.
